# Temio

App móvil para medir tu tiempo de trabajo y cumplir tus metas, con modos de
enfoque que hacen la experiencia distinta a un Pomodoro tradicional.

## Características

- Cronómetro libre y Pomodoro clásico
- Modos de trabajo: Bosque, Jefe, Flow, Libre y Clásico
- Metas por proyecto con progreso y fecha límite
- Historial y estadísticas (horas por día/semana, rachas)
- Perfiles para estudiantes, freelancers y developers
- Local-first: funciona sin internet y tus datos se quedan en tu celular

## Stack

Expo · React Native · TypeScript · Expo Router · NativeWind ·
expo-sqlite + Drizzle ORM · Zustand · Reanimated + Skia
